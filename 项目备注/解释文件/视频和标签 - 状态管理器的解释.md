# 状态管理器（Providers）说明文档

## 一、概述

在本视频管理应用中，采用 `Provider` 作为状态管理方案，通过 `MultiProvider` 注册了两个核心状态管理器：`VideoProvider`（视频状态管理）和 `TagProvider`（标签状态管理）。这些状态管理器封装了数据存储、业务逻辑和状态更新方法，实现了全应用范围内的数据共享和同步。

## 四、状态使用方式

```

&#x20; // 获取视频状态管理器

&#x20; final tagProvider = Provider.of\<TagProvider>(context);
```

## 五、扩展说明



* **状态更新通知**：当 `Provider` 中的状态（如 `_videos`、`_tags`）发生变化时，需调用 `notifyListeners()` 方法通知所有依赖该状态的组件重新构建（代码中已封装该逻辑）。

* **新增状态**：若需扩展状态（如 “当前播放的视频 ID”），可在对应 `Provider` 中添加变量及更新方法，例如在 `VideoProvider` 中添加 `String? currentPlayingVideoId` 并提供 `setCurrentPlayingVideoId(String id)` 方法。

* **性能优化**：通过 `Consumer` 或 `Selector` 组件可实现局部刷新，避免因状态更新导致的全页面重建（复杂页面推荐使用）。
