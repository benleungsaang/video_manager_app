# 安卓平板 Flutter 视频管理 APP 开发方案（精简版）

## 一、项目概述

### 1. 项目目标

开发一款基于安卓平板的 Flutter 跨端应用，核心实现**视频上传、标签管理、内网跨设备访问、视频播放检视、标签编辑、视频备注**功能，支持视频与标签关联管理，通过模块化设计实现多端（平板 APP、电脑网页、苹果手机网页）功能复用，提升开发维护效率与用户体验一致性。

### 2. 核心受众

需在内网环境下跨设备管理视频（如工作场景的会议视频、学习场景的教学视频），需要通过标签快速检索视频、检视视频内容并补充备注的用户。

### 3. 运行环境



* 主设备：安卓平板（Android 10.0+）

* 访问设备：电脑（Chrome/Firefox/Edge 最新版）、苹果手机（iOS 14.0+，Safari 浏览器）

* 网络环境：内网（Wi-Fi 局域网）

### 3. 架构设计（模块化分层）



* **数据层**：数据库操作（Hive）、文件 IO（本地存储）、网络请求（dio），封装统一接口供业务层调用。

* **业务层**：视频管理（含播放、上传）、标签管理、服务器控制，核心逻辑封装为独立仓库（Repository）。

* **UI 层**：平板 APP 页面、Web 端页面（复用组件），通过状态管理接收业务层数据，不包含复杂逻辑。

## 三、核心功能模块设计

### 1. 视频管理模块（全端通用）

#### 1.1 视频上传流程



| 步骤      | 操作细节                                  | 技术实现                                           | 跨端适配                      |
| ------- | ------------------------------------- | ---------------------------------------------- | ------------------------- |
| 1. 触发上传 | 平板：悬浮按钮；Web 端：顶部按钮（电脑支持拖拽上传）          | Flutter UI 组件复用，通过 Platform.isWeb 区分端类型调整样式    | 苹果手机端按钮固定在底部，点击区域≥44×44px |
| 2. 选择视频 | 弹出文件选择器，限制格式为 video/\*（mp4、mov、avi 等） | file\_picker 库，配置 type: FileType.video         | Safari 浏览器兼容处理，确保返回正确文件流  |
| 3. 进度跟踪 | 显示进度条（精确到 1%），不阻塞标题 / 标签输入            | dio 的 onSendProgress 回调，通过 ChangeNotifier 同步状态 | 平板 / 电脑：进度条在预览区下方；手机：顶部显示 |
| 4. 信息输入 | 标题（必填，≤50 字）；标签（多选，支持搜索 + 新建）         | 标题：TextFormField（长度校验）；标签：Wrap+Chip 组件         | 手机端标签区可滚动；电脑端支持回车快速添加     |
| 5. 启用保存 | 上传进度 100% 且标题非空时，按钮从禁用变可点击            | 监听 uploadProgress 和 titleController 状态         | 全端统一逻辑，禁用时灰色，可点击时蓝色       |
| 6. 提交保存 | 保存视频元数据，更新标签关联及视频数量                   | 调用 VideoRepository.save ()，事务性处理避免数据不一致        | 保存成功后实时刷新视频列表             |

#### 1.2 视频播放与编辑流程



| 步骤        | 操作细节                                     | 技术实现                                  | 跨端适配                     |
| --------- | ---------------------------------------- | ------------------------------------- | ------------------------ |
| 1. 触发播放   | 点击视频列表卡片，跳转至播放页                          | Navigator.push 跳转，传递视频 ID 参数          | 平板 / 电脑端支持双击视频卡片全屏播放     |
| 2. 视频播放控制 | 支持播放 / 暂停、进度拖动、音量调节、全屏切换、倍速播放（0.5x-2.0x） | chewie 封装播放器，监听播放状态同步进度               | 手机端触摸播放区显示控制栏，1.5 秒后自动隐藏 |
| 3. 标签编辑   | 显示已关联标签（带删除按钮），支持添加新标签 / 新建标签            | 复用 TagRepository，实时同步 tagIds 与标签数量    | 电脑端标签横向排列，手机端纵向滚动        |
| 4. 备注编辑   | 多行输入框（≤500 字），支持自动保存（每 3 秒 / 失去焦点时）      | TextFormField 配合 debounce 防抖，自动调用保存接口 | 手机端输入框适配键盘弹出，避免遮挡        |
| 5. 手动保存   | 提供手动保存按钮，作为自动保存的补充                       | 监听标签 / 备注变更状态，保存成功显示 Toast 提示         | 未保存修改时返回，弹窗提示是否放弃变更      |

#### 1.3 视频搜索功能



* 搜索范围：视频标题（模糊匹配）、关联标签（精确匹配）、备注（模糊匹配）

* 触发方式：输入关键词后按**回车键**触发搜索（避免频繁查询）

* 技术实现：Hive 索引查询，组合多条件返回结果

* 分页逻辑：默认一页 5 条，通过 ListView.builder 实现懒加载

#### 1.4 异常处理



* 上传中断：提示 “网络异常，上传失败，请检查网络后重试”

* 视频过大：校验文件大小（默认限制 10GB，可配置），超限提示 “视频过大（最大支持 10GB），请压缩后上传”

* 保存失败：提示 “保存失败，请稍后重试”，保留已输入信息

* 播放异常：视频格式不支持时提示 “无法播放该视频，请转换格式后重试”
