当前提供代码是否存在以下问题：1、视频应允许空标签，是否符合；2、上传时默认视频文件名为视频标题，当上传修改保存时，同时修改上传的文件名；3、没有被任何引用的标签，是否有设置自动删除逻辑；

根据提供的开发方案文档，针对三个问题的分析如下：
1. 视频是否允许空标签？
符合允许空标签的需求文档中视频上传流程的 “信息输入” 步骤提到标签为 “多选，支持搜索 + 新建”，但未强制要求必须选择标签。标签管理模块的 CRUD 操作也未对视频关联标签设置必填约束，因此默认支持视频不关联任何标签（空标签状态）。

2. 上传时是否默认以视频文件名为标题，且修改标题时同步修改文件名？
不符合该需求文档中视频上传流程的 “信息输入” 步骤明确将 “标题” 作为独立输入项（必填，≤50 字），但未提及 “默认使用视频文件名作为标题” 的逻辑，也未说明标题修改与原视频文件名的关联关系。当前设计中标题仅作为视频元数据存在，与实际视频文件的文件名无同步机制。

	--操作相关代码是要求加上

3. 未被引用的标签是否有自动删除逻辑？
无自动删除逻辑文档中标签管理模块仅描述了手动删除标签的操作（左滑 / 点击删除按钮），并明确需要用户确认 “删除后影响 X 个视频”。对于无关联视频的标签，方案中未提及自动清理机制，需用户手动判断并删除。

	-- 标签未被任何引用时自动删除
	在 tag_repository.dart 中实现

		视频删除时（移除视频关联的标签后）

以dhttpd + shelf开发平板启动本地 HTTP 服务，支持内网Web 端访问并功能复用，平板端功能：

◦ 功能复用：Web 端通过 Flutter WebView 加载 APP 页面，复用所有 UI 组件与业务逻辑，VideoGrid等组件中添加响应式布局，适配不同设备屏幕尺寸

◦ 跨域支持：服务器配置 CORS，允许内网所有设备访问
◦ 添加 WebSocket 实时同步多设备同时操作的状态

要让 Web 端通过浏览器访问并复用平板端的web_access_page.dart相关 UI，需要执行Flutter Web 编译，将 Flutter 代码编译为 Web 端可运行的静态资源（HTML/CSS/JS），然后让本地 HTTP 服务器托管这些资源

1. 确保 Flutter 项目支持 Web 平台
# 在项目根目录执行
flutter config --enable-web # 启用 Web 支持

2. 编译 Flutter Web 静态资源
将整个 Flutter 项目（包括web_access_page.dart等 UI 组件）编译为 Web 端可运行的文件

flutter build web


编译成功后，会在项目根目录生成 build/web 文件夹，包含以下核心文件：
	index.html：Web 入口页面
	main.dart.js：Flutter 代码编译后的 JS 文件
	assets/：静态资源（图片、字体等）

还需要将 Web 资源嵌入平板 APP 并正确读取路径



===============================================

1. 配置 pubspec.yaml，将 Web 资源纳入 APP 资源
打开 pubspec.yaml，添加 build/web 目录到资源列表：

flutter:
  assets:
    - build/web/
    - build/web/assets/
    - build/web/assets/fonts/

flutter clean
flutter build web

改用 AssetManifest API 或 AssetManifest.bin

但反而不会复制assets下的任何文件，包括根目录以及fonts等文件，需要显式在依赖中注明，有点奇怪
